整理日期：2026-11-07（北京时间）。范围：`scene_regularity_research/` 原始研究目录与 `scene_regularity_release/` 发布及模型实验目录。最新保存的实验汇总为 **2026-10-26 16:23 的起点未知类型预测评估**；本次没有重新训练或打开最终测试集。检查时未发现这两个项目的训练进程。

本报告按研究问题汇总当前证据，早期探索仅交代其用途，不把被替代的数值作为当前成绩。运行清单见 [experiment_runs.csv](experiment_runs.csv)，报告及结果文件索引见 [experiment_artifacts.csv](experiment_artifacts.csv)。文件修改时间仅用于定位新产物，不等同于实验实际开始时间。

本次盘点：**111 个运行目录**（110 份最终运行记录、1 个队列标记失败且无最终记录的运行），其中开发执行者运行 51 个、开发类型运行 7 个、已被替代的优化探索 16 个、数学退化验收 2 个、软件冒烟 35 个；另索引 **382 份 Markdown/JSON 产物**。统计分析及 B0 等并不都写 `run.json`，已另收录于产物索引；这些数字不是独立科学实验数。

## 1. 当前能够成立的判断

- **历史信息有用，执行者预测是目前证据较完整的方向。** 英超无历史摘要 M1⁻ 的 NLL 为 1.1543，加入人工历史摘要的 M1 为 1.1321；在 M1⁻ 上学习 B0 历史项为 1.1461。人工摘要的收益尤其集中于开场阶段。
- **更复杂的实体表示和图并未稳定超过简单历史基线。** 英超 B0-M1 为 1.1275，M2 为 1.1276；图消息传递的配对增益区间覆盖零。不能将“存在层级关系”直接写成“图结构已经有效”。
- **动作类型方向出现了执行者辅助监督的收益。** 已知起点时 T0→T1w 的 NLL 为 1.0257→1.0154；未知起点时为 1.1374→1.1263。显式执行者混合 T2 未超过 T1w 的 NLL。这组实验关闭了候选人的跨比赛历史特征，还没有证明历史改善动作类型预测。
- **冷启动和跨联赛迁移仍是待验证贡献。** 已有冷启动候选二元损失、低历史目标切片、多联赛分别估计及合训结果；没有完成专门的新球员留出验证，也没有严格的英超训练→未见联赛迁移成绩。
- 所有预测结果都是开发期结果。单次训练模型的比赛 bootstrap 区间不包含训练种子、反复选模型的全部不确定性，不能替代最终测试证据。

## 2. 实验范围和不同指标口径

| 实验层 | 数据范围 | 目标及评价单位 | 解释边界 |
|---|---|---|---|
| 早期探索 | 英格兰训练期 266 场 | 球队动作、球员动作、候选人参与；通常以 10⁻³ nats/行报告 | 发现假设，部分使用早期数据定义 |
| 当前存在性分析 | 法 322、德 260、意 322、西 323 场非测试比赛 | 群体效应、实体方差、类型解释等统计检验 | 修正后的既有确认资格，不是新样本再确认 |
| 当前可学习性 | 五联赛分别估计，再合并；每队前 19 场估计实体项、其后评分 | 执行者为二元候选行，动作属性为二元动作行；单位 10⁻³ nats/行 | 人群部分在非测试期交叉拟合，不是全组件严格前推预测 |
| 执行者模型：五联赛 | 1,272 场训练、278 场验证 | 验证 319,603 个目标，318,858 个可达；NLL 为 nats/动作 | 合训开发评估，不是零样本迁移 |
| 执行者模型：英超 | 266 场训练、57 场验证 | 验证 65,133 个目标，64,975 个可达 | 明确区分英超单独训练与五联赛训练 |
| 类型模型 | 英超单独训练和验证 | 64,975 个可达目标、10 类运动战动作 | 排除了不可达目标，不是所有原始 Wyscout 事件 |

执行者模型的 NLL 仅计可达目标；Top-k 保留全部目标，不可达记未命中。主执行者评估采用随机打破并列的精确期望，ECE 同口径。类型实验本次已从保存预测复现 NLL、Top-1、Top-3 和 11 项 bootstrap 比较；没有真实标签并列分数影响这些类型准确率。

“冷启动候选人（二元）”是候选行的二元对数损失，越低越好；“场上有历史少于 5 场的候选人”是目标切片，不能等同于“真实执行者为新球员”。早期二元行收益不能与后来多类动作 NLL 直接比大小，也不能直接换算为准确率。

模型主要采用条件 A：目标球队、目标时间和目标起点已知。后续起点未知实验只移除起点相关输入，目标时刻仍已知。静态位置使用数据商赛后快照，进一步严格时序验证需要无该角色输入的正式对照；目录中的相应 smoke 不能代替正式结果。

## 4. 当前存在性结果

四个确认联赛：主族 **7/10**、次族 **15/18** 保留确认。修正分析沿用“只撤回、不新增”的资格规则，因此未确认不一定是 p 值不显著。

支持较清楚的内容包括：位置格子×步数、球员×步数、球员×阶段、球员/位置×对方事件，以及若干球队动作倾向。球队长传、回传、向前的步数差异存在，但它们能否产生预测收益需要另验。

未得到预期支持的内容包括：主动夺回→快速进攻的预期正方向、各队这一效应的差异、球队类型×步数的前推收益。球员类型解释后的残余方差比约 **0.85**，高于登记阈值 **0.8**，不能称类型已经充分解释个体差异。完整各项估计、Holm 和资格见 [existence.md](existence.md)。

## 6. 执行者预测：模型定义

| 名称 | 内容 |
|---|---|
| R1 | 按距候选人上次出手的本方动作数打分，训练一个衰减系数 |
| R2 | 按候选人先验位置距目标起点的距离打分，训练一个距离系数 |
| M0 | 人群 GBDT，情境和候选人状态；动作内归一化 |
| M0p | M0 加入候选人本场此前动作池化 |
| M1 | 32 条历史记录的注意力编码＋候选人状态和本场动作池化，包含人工跨比赛历史摘要 |
| M1⁻ | 去掉候选人跨比赛历史摘要，保留本场信息、数据商角色和门将标记 |
| B0-g / B0-M1 / B0-M1⁻ | 分别叠加在 M0 / M1 / M1⁻ 上的独立实体×场景参数，按层正则化；凸条件 logit |
| M2 | 将实体×场景项参数化为层级低维表示，使用得分空间惩罚 |
| M3 | 历史统计特征经逐节点编码，不含 ID 残差 |
| M2+3 | 历史统计＋层级 ID 表示 |
| M4 | M2+3 加历史关系消息传递；另有去相似边、去 ID 对照 |
| D | 不受指定场景形式限制的诊断模型 |

当前完整实体模型比较主要建立在**含历史摘要的 M1** 偏移量上。M1⁻＋B0 的英超试点已完成，但不能把整个 M2–M4 系列当作已全部切换到 M1⁻ 重跑。

M1 对 M1⁻ 在开场 15 分钟的 NLL 降幅为 **0.0976 [0.0868, 0.1086]**。当真实执行者本场尚未有动作时，两者 NLL 为 **1.7318→1.3978**，这是本场信息不足切片的描述，不等同于跨比赛新球员冷启动。冷启动候选二元损失的 M1 对 M1⁻ 区间跨零；近期替补有约 **0.0062** 的收益。

此前讨论的 1.1321→1.1275，在统一当前口径下 Top-1 为 **58.16%→58.38%**，并非准确率下降。五联赛合训的 60% 左右成绩不能混作这组英超独立训练结果。

## 10. 最近实验：执行者信息与动作类型

全部英超单独训练，单种子 20260715，120 轮；按验证类型 NLL 选择 checkpoint。10 类为 short_pass、long_pass、cross、through_ball、head_pass、carry、take_on、shot、clearance、touch。T0 只用情境；T1 加候选人注意力汇总；T1w 再加执行者损失；T2 使用预测执行者分布混合各执行者的条件动作分布；T3 用 T2 同一 checkpoint 的真实执行者条件输出作诊断。

解释限制：

- T3 使用预测时未知的真实执行者，是 oracle 诊断，不是可部署成绩或数学上的严格上限；T3−T2 不能精确归因于执行者误差这一因素。

- 未知起点仍已知目标时间；尚未完成目标时刻、目标球队和起点都未知的完整下一事件任务。

## 13. 跨联赛、冷启动及下一步证据缺口

多联赛证据已经包含三层：四联赛统计规律复核；五联赛各自估计的可学习性；五联赛合训模型在各联赛验证。三者均不能替代“英超训练后直接迁移到其他联赛”的实验。

开发期各联赛没有统一日历截止：例如英超验证从 2018-02-11 开始，而意甲训练延伸到 03-10。合训共享参数会吸收其他联赛更晚时期信息。因此 M1 合训在英超比英超单训的 NLL 改善约 0.0397，只能报告开发合训收益，不能称严格时间外推。转会球员的跨联赛 ID 与按联赛构建的历史统计也有不对称，正式迁移需单列。

冷启动方面，已有自然低历史切片和候选二元损失，但 B0/M2/图的主要冷启动收益并不稳定。更有力的已有信号是“开场/本场尚无动作时历史有用”；这一问题与“跨比赛历史为零的新球员”必须分开。

尚未完成且不能作为论文已实现贡献：外部基线正式对比、多随机种子确认、严格时间测试、英超→其他联赛迁移、专门新球员留出、历史增强类型预测、完整未知下一事件联合预测、最终模型预测增益的检测下限和最终测试。研究任务仍应由这些实验中的稳定收益决定。
