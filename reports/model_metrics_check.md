## 评价口径

- NLL 仅计算执行者可达目标；Top-k、ECE 保留全部目标，不可达目标命中为 0。
- Top-k 使用随机打破并列的精确期望；ECE 使用同一个期望 Top-1 命中率，15 个等宽置信度区间。
- 若 g 个候选得分更高，m 个候选与执行者同分（包括本人），期望 Top-k 为 `clip(k-g,0,m)/m`。不将所有并列候选都视为命中，也不根据球员 ID 决定命中。
- 主实验和新增外部基线现在共用 `src/ranking_metrics.py`。先前新增基线的 ID 排序与主实验口径不同，已统一；保存的三组冒烟预测已按此重算指标，模型权重不变。
- 在本次五联赛 M1 分数上，两种并列处理给出相同的 Top-1、Top-3；R1 的期望 Top-1 为 0.126981，按 ID 排序为 0.127073。
- 五联赛开发划分没有统一日历截止，因此这些数字仅用于开发比较，不构成严格时间外推或跨联赛迁移证据。
